O que é HTML

A respeito de linguagem de marcação.

HTML, que significa HyperText Markup Language (Linguagem de Marcação de Hipertexto), é a linguagem padrão fundamental utilizada para criar e estruturar páginas e aplicações na web.
Ela funciona como o "esqueleto" de um site, organizando conteúdos como textos, imagens, links e vídeos para que os navegadores (como Chrome, Firefox, Safari) saibam como exibi-los ao usuário
